01

Profile

I am a software engineering researcher and engineer working where requirements, testing, and low-code platforms meet.

My doctoral research asks how low-code platforms can validate requirements before they become software. I work with language models, BPMN 2.0, and Petri nets, and I care about making formal methods useful to people who build software every day.

Before my PhD, I earned a master's degree in Computer Science from Amirkabir University of Technology and a bachelor's degree from Shahed University, graduating first in my class in both. Since 2019 I have worked as a Java and Spring engineer, and I have taught programming and web development at Sharif, Shahed, and Amirkabir. Alongside this, I have four peer-reviewed publications.

Research

Four threads run through my work.

AI for software engineering

Language models and machine learning for requirements, testing, and code generation.

Low-code platforms

Knowledge-based support for requirements validation and testing where code is largely generated.

Business process modeling

Structural soundness and static analysis of BPMN 2.0 models, with roots in Petri nets.

Software testing and requirements

Validating what a system must do, and generating tests that check it.
